# 体脂肪率

個人向け体重管理ダッシュボード

## ▶ Androidアプリ（Health Connect 自動連携）

**[weight-log.apk をダウンロード](https://github.com/NobusatoKomatsu/weight-log/releases/download/app/weight-log.apk)**

AiLink などが Health Connect に書き込んだ体重・体脂肪率を、アプリを開くたびに自動で取り込みます。
