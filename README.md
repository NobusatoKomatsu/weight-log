# アプリ一掃（Androidアプリ）

使っていないアプリをまとめて選んで、続けて削除するアプリです。ソースは `sweep-android/` にあります。

**[app-sweep.apk をダウンロード](https://github.com/NobusatoKomatsu/weight-log/releases/download/sweep/app-sweep.apk)**

- 自分で入れたアプリを「使っていない順 / 大きい順 / 名前順」で一覧表示（最後に使った日と容量つき）
- 「1か月 / 3か月 / 半年 / 1年」使っていないアプリをワンタップでまとめて選択
- 選んだアプリを続けて削除（Android の決まりで、確認は 1個ずつ出ます）。終わると空いた容量を表示
- 消したくないアプリは長押しで「残すアプリ」に（まとめて選択の対象から外れます）
- 調べた内容は端末の外には送りません（通信の権限なし）

最後に使った日とデータを含めた容量を出すには、「使用状況へのアクセス」の許可が必要です（アプリが案内します）。許可しない場合は、入れた日とアプリ本体の大きさで表示します。
