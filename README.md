# 画面メモ（Androidアプリ）

買い物メモなど、ToDo アプリに入れるほどでもない日常のメモを、スマホの画面に出しておくアプリです。ソースは `memo-android/` にあります。

**[screen-memo.apk をダウンロード](https://github.com/NobusatoKomatsu/weight-log/releases/download/memo/screen-memo.apk)**

- **表示する場所を選べる**（いくつでも）
  - 画面の上：どのアプリを使っていても、メモが浮かんで表示されます。位置は 9 か所から選べ、表示中のメモを指でドラッグして動かせます（タップで編集）
  - ホーム画面：ウィジェットとして表示
  - ロック画面・通知欄：通知として表示
- **文字の大きさ（10〜80）・文字の色・背景色・太字**を選べます
- **🎤 音声入力**：話した内容がメモに入ります
- **用が済んだら**：画面の上のメモは長押し、通知は「済み」ボタンで非表示に（一覧からまた表示できます）
- **スワイプで削除**：いらなくなったメモは一覧で左右にスワイプ。10 秒間は「元に戻す」で戻せます（Gmail のアーカイブと同じ）
- **📅 カレンダー連携**：メモに「明日15時」「10/31」「来週金曜」などの日付があると、カレンダーの予定作成画面を日時・タイトル入力済みで開きます（保存時にも確認）。追加先は一覧画面の下で「自動 / Googleカレンダー / Outlook（Microsoft 365）」から選べます。Outlook アプリがなければブラウザの Outlook で開きます
- **すぐ書ける**：アプリのアイコンを長押し →「新しいメモ」「音声でメモ」
- メモは端末の中にだけ保存されます

はじめて「画面の上」に表示するときは「他のアプリの上に重ねて表示」の許可、「ロック画面・通知欄」には通知の許可が必要です（アプリが案内します）。

Google Play への申請手順と、入力する文章は [memo-android/store/README.md](memo-android/store/README.md) にあります。
