# 画面メモ Google Play 申請ガイド

Play Console に入力する内容と、手順をまとめています。上から順に進めてください。

## 0. 用意するもの

| もの | 場所 |

## 1. デベロッパーアカウント

「Android通知の時限シャットダウン」を公開している**組織用のデベロッパーアカウント**に、新しいアプリとして追加します（新しい登録や登録料は不要）。

- 組織用アカウントには、個人アカウントにある「12 人で 14 日間のクローズドテスト」の条件はかかりません。社内で数人に「内部テスト」で配って確認してから、製品版に出せば十分です
- ストアに表示されるデベロッパー名・連絡先は、そのアカウントのもの（会社）になります

## 1.5 公式サイトとメール（memoru.info）

通知パージ（notification.sucks）と同じく Cloudflare で公開する想定です。

**サイト**（Cloudflare Pages）
1. Cloudflare のダッシュボード →「Workers & Pages」→「作成」→「Pages」→「Git に接続」で `NobusatoKomatsu/weight-log` を選ぶ
2. ビルドの設定：フレームワーク「なし」、ビルドコマンドは空、**ビルド出力ディレクトリ `memoru-site`**、本番ブランチ `main`
3. 「カスタムドメイン」に `memoru.info` を追加
4. https://memoru.info/privacy と https://memoru.info/delete が開けることを確認（`.html` なしの URL で開けます）

**メール**（Cloudflare Email Routing）
- `memoru.info` の「メール」→「Email Routing」で `support@memoru.info` を作り、普段読んでいるアドレスへ転送

## 2. アプリを作成

- アプリ名：`画面メモ`
- デフォルトの言語：日本語
- アプリ / ゲーム：アプリ
- 無料 / 有料：無料

パッケージ名は `info.memoru.app` です（memoru.info に合わせたもの）。**最初にアップロードした後は変更できません。** 変えたい場合はアップロード前に言ってください。

## 3. ストアの掲載情報

**アプリ名**（30 文字以内）
```
画面メモ - 画面に出しっぱなしの買い物メモ
```

**簡単な説明**（80 文字以内）
```
買い物メモやちょっとした用事を、スマホの画面・ホーム画面・ロック画面に表示。音声入力とカレンダー連携も。
```

**詳しい説明**
```
「牛乳とパンを買う」「15時に電話」——ToDo アプリに入れるほどでもない、毎日のちょっとしたメモを、スマホの画面に出しておくアプリです。

■ 表示する場所を選べます（いくつでも）
・画面の上：どのアプリを使っていても、メモが浮かんで表示されます。位置は 9 か所から選べて、指でドラッグして動かせます
・ホーム画面：ウィジェットとして表示
・ロック画面・通知欄：スマホを開かなくても確認できます

■ 見やすく
・文字の大きさ（10〜80）、文字の色、背景の色、太字を選べます
・背景を透明にして、文字だけ表示することもできます

■ すぐ書ける
・🎤 音声入力：話すだけでメモになります
・アプリのアイコンを長押し →「新しいメモ」「音声でメモ」ですぐに書けます

■ 用が済んだら
・画面の上のメモは長押し、通知は「済み」ボタンで消せます
・メモは一覧に残るので、次の買い物でまた表示できます
・いらなくなったメモは、一覧で左右にスワイプして削除。10 秒間は「元に戻す」で戻せます

■ カレンダー連携
・「明日15時 歯医者」「10/31 ゴミ出し」「来週金曜 飲み会」のように日付を書くと、Google カレンダーや Outlook（Microsoft 365）に予定として追加できます

■ 安心
・メモはスマホの中にだけ保存されます。外部のサーバーには送りません
・広告なし、アカウント登録なし
```

**グラフィック**：アイコン、フィーチャーグラフィック、スクリーンショット（上の表）

**カテゴリ**：仕事効率化　／　**連絡先メールアドレス**：`support@memoru.info`　／　**ウェブサイト**：`https://memoru.info`

## 4. アプリのコンテンツ（ポリシーの申告）

| 項目 | 回答 |
|---|---|
| プライバシーポリシー | `https://memoru.info/privacy` |
| 広告 | 含まない |
| アプリのアクセス権 | すべての機能に特別なアクセス権は不要（ログインなし） |
| コンテンツのレーティング | カテゴリ「その他（ユーティリティ、生産性向上…）」→ 暴力・性的表現・ユーザー間のやり取り・位置情報の共有・購入などはすべて「いいえ」 |
| ターゲットユーザー | 13 歳以上（子ども向けではない。通知パージと同じ） |
| ニュースアプリ | いいえ |
| 政府機関のアプリ / 金融 / 健康 | いいえ |
| データ セーフティ | 「必要なユーザーデータを収集・共有しますか？」→ **いいえ**（下の補足） |
| データの削除 | データを収集しないので URL の入力は不要だが、聞かれたら `https://memoru.info/delete` |

**データ セーフティの補足**：メモは端末内だけに保存し、外部に送信しません。音声入力は端末の音声入力アプリ（Google など）を呼び出すだけで、本アプリは音声を受け取りません。カレンダーへの追加は、利用者が選んだカレンダーアプリの予定作成画面を開くだけです。

### フォアグラウンド サービスの権限（必須）

「アプリのコンテンツ」→「フォアグラウンド サービスの権限」で **特殊な用途（Special use）** を選び、次を入力します。

**説明**
```
ユーザーが「画面の上」に表示すると選んだメモを、他のアプリを使っている間も画面に重ねて表示し続けるために使います（SYSTEM_ALERT_WINDOW によるオーバーレイ表示）。サービスはユーザーがメモの表示をオンにしたときだけ動き、表示するメモがなくなると止まります。通知から「画面メモを表示中」であることが常にわかります。
```

**動画**：次の流れを 30 秒ほど画面録画し、YouTube に「限定公開」でアップしてリンクを貼ります。
1. アプリでメモを書き、「画面の上」にチェックして保存
2. ホーム画面や別のアプリ（ブラウザなど）を開いても、メモが表示されたままになっている
3. 通知欄に「画面メモを表示中」が出ている
4. メモを長押しして消すと、通知も消える

## 5. スクリーンショット

縦向きで 2〜8 枚（実機のスクリーンショットでOK）。おすすめ：
1. 別のアプリの上にメモが浮かんでいる画面（例：買い物リストを表示したままブラウザ）
2. 編集画面（文字の大きさ・色・プレビュー）
3. 画面の位置を選ぶところ（スマホの形の 9 マス）
4. ホーム画面のウィジェット
5. ロック画面の通知
6. カレンダーに追加するボタン

## 6. リリース

1. 「テスト」→「内部テスト」でトラックを作り、確認してくれる人を登録（任意だが、製品版の前に一度おすすめ）
2. 「新しいリリースを作成」→ `screen-memo.aab` をアップロード
   - **Play アプリ署名**はそのまま有効に。いま GitHub の Secrets（`KEYSTORE_B64`）にある鍵が「アップロード鍵」になります。**この鍵をなくすと更新できなくなるので、バックアップを残してください**（なくした場合も、組織アカウントのオーナーが Play Console から鍵の再設定を申請できます）
3. リリースノート：
   ```
   はじめてのリリースです。
   ```
4. 問題なければ同じ AAB を「製品版」でリリース → 審査（数日ほど）→ 公開

### 2 回目以降の更新

`main` に入れると、新しい `screen-memo.aab`（バージョンコードは自動で増えます）が Releases に置かれるので、それをアップロードするだけです。
