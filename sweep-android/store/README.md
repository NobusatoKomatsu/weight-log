## 1. デベロッパーアカウント

「Android通知の時限シャットダウン」を公開している**組織用のデベロッパーアカウント**に、新しいアプリとして追加します（新しい登録や登録料は不要）。

## 1.5 公式サイトとメール（applications.sucks）

通知パージ・画面メモと同じく、Cloudflare の Workers で公開します。サイトの中身は `sweep-site/public/`（トップ・プライバシーポリシー・404）、設定は `sweep-site/wrangler.jsonc` です。

**① applications.sucks を Cloudflare に追加**
1. Cloudflare の左メニュー「ドメイン」→「ドメインを追加」→ `applications.sucks` → プランは Free
2. 表示された 2 つのネームサーバーを、ゴンベエドメインのドメインマネージャーで設定する（登録時は「無料DNS」にしてあるので書き換える）
3. 「アクティブ」になるまで待つ（数分〜数時間）

**② サイトを公開（Workers）**
1. 左メニュー「コンピュート」→「Workers & Pages」→「作成」→「Git リポジトリをインポート」→ `NobusatoKomatsu/weight-log`
2. 設定：
   - プロジェクト名：`app-sweep`
   - 本番ブランチ：`main`
   - **ルートディレクトリ（パス）：`sweep-site`**
   - ビルドコマンド：空のまま　／　デプロイコマンド：`npx wrangler deploy`
3. デプロイ後、Worker の「設定」→「ドメインとルート」→「追加」→「カスタムドメイン」→ `applications.sucks`
4. （任意）「設定」→「ビルド」→「ビルドの監視パス」を `sweep-site/*` にすると、アプリだけ変えたときに無駄なデプロイが走りません

**③ メール**
- `applications.sucks` の「メール」→「Email Routing」で `support@applications.sucks` を作り、普段読んでいるアドレスへ転送

## 2. アプリを作成

正式な名前（ストア・公式サイト）は「Androidアプリ一掃アプリ」、ホーム画面のアイコンの下に出る名前は短く「アプリ一掃」です（通知パージと同じ分け方。長い名前はホーム画面で途中までしか表示されないため）。

- アプリ名：`Androidアプリ一掃アプリ`
- デフォルトの言語：日本語
- アプリ / ゲーム：アプリ
- 無料 / 有料：無料

## 3. ストアの掲載情報

**アプリ名**（30 文字以内）
```
Androidアプリ一掃アプリ
```

**簡単な説明**（80 文字以内）
```
使っていないアプリがひと目でわかる。いらないアプリだけチェックを外して、まとめて削除。確認つきで安心。
```

**詳しい説明**
```
気づけば増えているアプリを、まとめて整理するためのアプリです。

■ 使い方
・はじめは、すべてのアプリが「残す」になっています
・いらないアプリだけ、タップしてチェックを外します
・「削除」を押すと、選んだアプリを続けて削除します

■ 選びやすく
・「使っていない順」「大きい順」「名前順」に並べ替え
・最後に使った日と、使っている容量を表示
・削除でどれだけ空くかが、選びながらわかります

■ 誤って消さないために
・チェックを外したアプリは赤く表示
・削除の前に、消すアプリをすべて並べて確認。「確認しました」にチェックを入れるまで削除は始まりません
・さらに Android の確認が 1個ずつ出ます。途中でやめることもできます
・最初から入っているアプリ（システムアプリ）は対象外です
・外したチェックは保存しません。開き直すと、すべて「残す」に戻ります

■ 安心
・調べた内容はスマホの外に送りません（インターネットに接続しません）
・広告なし、アカウント登録なし

※ 最後に使った日と正確な容量の表示には「使用状況へのアクセス」の許可が必要です。許可しなくても使えます（入れた日とアプリ本体の大きさで表示します）。
※ 削除したアプリとそのデータは元に戻せません。
```

**グラフィック**：アイコン、フィーチャーグラフィック、スクリーンショット（上の表）

**カテゴリ**：ツール　／　**連絡先メールアドレス**：`support@applications.sucks`　／　**ウェブサイト**：`https://applications.sucks`

## 4. アプリのコンテンツ（ポリシーの申告）

| 項目 | 回答 |
|---|---|
| プライバシーポリシー | `https://applications.sucks/privacy` |
| 広告 | 含まない |
| アプリのアクセス権 | すべての機能に特別なアクセス権は不要（ログインなし） |
| コンテンツのレーティング | カテゴリ「その他（ユーティリティ、生産性向上…）」→ すべて「いいえ」 |
| ターゲットユーザー | 13 歳以上（子ども向けではない） |
| ニュースアプリ / 政府機関 / 金融 / 健康 | いいえ |
| データ セーフティ | 「必要なユーザーデータを収集・共有しますか？」→ **いいえ**（下の補足） |

**データ セーフティの補足**：入っているアプリの一覧・最後に使った日時・容量は、端末の中で画面に表示するためだけに読み取り、端末の外へ送信しません（アプリは通信の権限を持っていません）。Google Play の定義では、端末の外に出ないデータは「収集」に当たりません。

### 審査で見られやすい点と、このアプリの対応

| 点 | 対応 |
|---|---|
| すべてのアプリの一覧取得（`QUERY_ALL_PACKAGES`） | **使っていません。** ホーム画面から開けるアプリだけを `<queries>` で取得するので、申告フォームは不要です |
| 使用状況へのアクセス（`PACKAGE_USAGE_STATS`） | 設定画面を開く前に、読み取る内容・目的・外部に送らないことをアプリ内で説明し、同意した場合だけ設定画面へ進みます（「目立つ開示」）。許可しなくても使えます |
| アプリの削除（`REQUEST_DELETE_PACKAGES`） | Android の削除確認画面を開くだけです。削除は必ず利用者が 1個ずつ承認します |
| 誤解を招く表示 | 「高速化」「ウイルス」「メモリ解放」などの表現は使っていません。ストアの文章にも入れないでください |

審査で使用状況へのアクセスの説明を求められたら、次を使ってください。
```
各アプリを最後に使った日時と使用容量を一覧に表示し、利用者が使っていないアプリを見つけて削除できるようにするために使います。これは本アプリの中心の機能です。読み取った情報は端末内で表示するだけで、保存も外部への送信も行いません（INTERNET 権限なし）。許可の前にアプリ内で目的を説明し、許可しない場合も本アプリは利用できます。
```

## 5. スクリーンショット

縦向きで 2〜8 枚（実機のスクリーンショットでOK）。おすすめ：
1. 一覧（使っていない順。最後に使った日と容量が見えている）
2. いくつかチェックを外して、赤く表示されている画面と下の「○個を削除」ボタン
3. 削除前の確認画面（消すアプリの一覧と「確認しました」のチェック）
4. 「使用状況へのアクセスについて」の説明画面

## 6. 事前登録

製品版の前に、事前登録を出しておきます（通知パージ・画面メモと同じ流れ）。事前登録の画面は、2〜5 の入力が終わってから使えます。

1. Play Console でアプリを開き、左メニュー「テストとリリース」→「テスト」→「事前登録」
2. 「新しいリリースを作成」→ `app-sweep.aab` をアップロード（ここでパッケージ名 `sucks.applications.sweep` が確定します）
3. リリースノートは「はじめてのリリースです。」
4. 「国 / 地域」タブで「国 / 地域を追加」→ 日本
5. 「審査に送信」→ 審査が通ると、ストアに「事前登録」ボタンつきで表示されます

- 事前登録を始めたら、**90 日以内に製品版を公開**する必要があります
- 事前登録が公開されたら教えてください。公式サイトの「Google Play で近日公開」を、ストアへのリンクつきの「事前登録受付中」に変えます
- メニューの名前や場所は Play Console の更新で変わることがあります。見当たらないときは、画面のスクリーンショットを送ってください

## 7. リリース

1. 「テスト」→「内部テスト」でトラックを作り、確認してくれる人を登録。**製品版の前に、実機で次を必ず確認してください**
   - 一覧にシステムアプリが出ないこと
   - チェックを外したアプリだけが削除され、ほかは残ること
   - Android の確認で「キャンセル」すると、そのアプリが残り、続けるかどうかを聞かれること
2. 「新しいリリースを作成」→ `app-sweep.aab` をアップロード
   - **Play アプリ署名**はそのまま有効に。GitHub の Secrets（`KEYSTORE_B64`）にある鍵が「アップロード鍵」になります。**この鍵をなくすと更新できなくなるので、バックアップを残してください**
3. リリースノート：
   ```
   はじめてのリリースです。
   ```
4. 問題なければ同じ AAB を「製品版」でリリース → 審査（数日ほど）→ 公開
